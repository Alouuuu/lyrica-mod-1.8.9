## Lyrica 0.9.4 para Minecraft 1.8.9 (Forge)

Primeira versão do **port não oficial** do [Lyrica](https://github.com/fakemaluco/lyrica-mod) para **Minecraft 1.8.9 com Forge**. É baseado no Lyrica 0.9.4 e tem a mesma licença (AGPL-3.0).

- Letras sincronizadas palavra por palavra no HUD, com as mesmas animações, brilho e fontes do Lyrica original.
- Funciona com Spotify (conta conectada ou detecção de mídia do Windows), YouTube Music (pela extensão do navegador) e outros players detectados pelo Windows.
- Tradução e romanização das letras, fontes do Google Fonts e letras 3D no mundo.
- Pressione **L** para abrir as configurações. Também existe uma tecla para mostrar ou ocultar as letras, sem atalho padrão. As duas podem ser trocadas em *Controles*.
- O mod avisa quando sai uma versão nova deste port.

**Diferenças em relação às versões Fabric:** vídeos de capa (Spotify Canvas e capas animadas), modo karaokê, presença e integração com o Jade não estão disponíveis. Capas em WebP ou AVIF são trocadas por JPEG ou PNG quando o servidor oferece. A iluminação do terreno pelas letras 3D vem desligada por padrão, porque reconstrói chunks.

**Instalação:** coloque `lyrica-0.9.4-1.8.9.jar` na pasta `mods` de um perfil com **Forge 1.8.9** (11.15.1.2318). Funciona com o Java 8 do launcher. O JAR já inclui o **bridge nativo para Windows x64**.

Problemas deste port devem ser relatados neste repositório, não no Lyrica original.

## Lyrica 0.9.4 for Minecraft 1.8.9 (Forge)

The first release of the **unofficial port** of [Lyrica](https://github.com/fakemaluco/lyrica-mod) to **Minecraft 1.8.9 with Forge**. It is based on Lyrica 0.9.4 and uses the same license (AGPL-3.0).

- Word-synced lyrics on the HUD, with the original's animations, glow and fonts.
- Works with Spotify (account connection or Windows media detection), YouTube Music (through the browser extension) and other players Windows detects.
- Lyrics translation and romanization, Google Fonts, and 3D lyrics in the world.
- Press **L** to open the settings. A show/hide lyrics key is also available, unbound by default. Both can be changed in *Controls*.
- The mod tells you when a new version of this port is out.

**Differences from the Fabric builds:** cover videos (Spotify Canvas and animated covers), karaoke mode, presence and the Jade integration are not available. WebP and AVIF covers are replaced with JPEG or PNG when the server offers them. Terrain lighting from 3D lyrics is off by default because it rebuilds chunks.

**Installation:** put `lyrica-0.9.4-1.8.9.jar` in the `mods` folder of a **Forge 1.8.9** profile (11.15.1.2318). It runs on the launcher's Java 8. The JAR includes the **Windows x64 media bridge**.

Please report issues with this port in this repository, not in the original Lyrica.
